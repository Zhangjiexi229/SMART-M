## 4. 供电架构

```
12V 适配器 ──┬─ 电机驱动板（功率回路，经继电器 COM/NO 通断）
             └─ 5V 降压（AMS1117-5.0 / MP1584）──┬─ 核心板 5V-IN → 板载 3.3V LDO
                                                 ├─ 继电器 VCC（5V）
                                                 └─ 独立 AMS1117-3.3 → ESP8266 VCC（单独一路，≥300mA）
    传感器 / OLED / 蜂鸣器：3.3V（核心板 3V3 或独立 3.3V，与 STM32 共地）
```

## 5. 与旧板（小达 M4 核心板 v1.2）关键差异

| 项 | 旧板 | 新板（本表） |
|----|------|-------------|
| 芯片 | STM32F407（LQFP100） | STM32F407VET6（LQFP100） |
| SHT30/QMI8658/OLED | I2C1 PB8/PB9 共用（OLED 同总线） | 总线1 PB8/PB9 挂三传感器；**OLED 拆独立总线2 PD6/PD7** |
| QMI8658 地址 | 0x6B | **0x6B（本模块 AD0 板上固定接地，实测；悬空模块为 0x6A）** |
| INA226 | 独立 I2C2 PB10/PB11（与 USART3 冲突） | 并入总线1 PB8/PB9 |
| ESP8266 | 板载 P1 接口 | **外接** USART3 PB10/PB11，独立 3.3V |
| 继电器 | PE2 | **PA4** |
| 蜂鸣器 | PE3（板载） | **PA5 外接**（新板无板载） |
| 矩阵键盘 | 行 PE4-PE7 / 列 PE8-PE11 | **行 PE2/PE6/PE7/PE10，列 PE8/PE9/PE11/PE12** |
| 板载 LED | - | PA6/PA7（低电平点亮） |
| HC-SR04（预留） | PA0/PA1 | PC11(Trig)/PE5(Echo) |
