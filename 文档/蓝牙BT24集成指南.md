# 蓝牙 BT24 集成指南（微信小程序远程监控）

> 在 SMART-M v3.0 基础上新增 **大夏龙雀 DX-BT24** BLE 串口透传模块，
> 手机微信小程序通过 BLE 直连设备：实时查看电机运行数据、远程控制继电器 / LED / 蜂鸣器。
> 与华为云 MQTT 通道并存，互不影响，共用同一业务入口（`APP_Relay_Control` / `BSP_LED_*`）。

---

## 1. 硬件接线

BT24 模块共 26 脚，本项目只需 4 根线（推荐使用模块的排针引脚 1/2/12/13）：

| BT24 引脚 | 模块脚位 | 接到 STM32F407VET6 | 说明 |
|---|---|---|---|
| UART-TX | 1 | **PA3**（USART2_RX） | 模块发 → 单片机收 |
| UART-RX | 2 | **PA2**（USART2_TX） | 单片机发 → 模块收 |
| VBAT | 12 | **3.3V** | 供电 2.8~3.6V，典型 3.3V |
| GND | 13（或 14） | **GND** | 共地 |

> 可选：LINK-STATUS（17 脚）接任意空闲 GPIO 可硬件判断连接状态，本项目使用
> `AT+NOTI1` 软件方式判断，无需接线。

**接线示意：**

```
STM32F407VET6              DX-BT24
  PA2 (USART2_TX)  ───────>  UART-RX (2)
  PA3 (USART2_RX)  <───────  UART-TX (1)
  3.3V             ───────>  VBAT   (12)
  GND              ───────>  GND    (13)
```

> ⚠️ 模块为 **3.3V 供电**，严禁接 5V；TX/RX 交叉连接（MCU TX→模块 RX）。

## 2. 模块参数与 AT 指令

出厂默认参数（无需任何配置即可使用）：

| 参数 | 值 |
|---|---|
| 串口 | **9600 / 8 / N / 1**（与 USART2 一致） |
| BLE 服务 UUID | `FFE0` |
| Notify/Write 特征 | `FFE1` |
| Write 特征 | `FFE2` |
| 设备名 | `BT24` |
| 工作模式 | 未连接=AT 命令模式；被连接=透传模式 |

**可选 AT 配置**（用 USB 转 TTL 以 9600 连接模块，或直接发给串口 2）：

| 功能 | 指令 | 说明 |
|---|---|---|
| 改名 | `AT+NAME你的名字` | 需重启生效 |
| 改波特率 115200 | `AT+BAUD7` | 需重启生效；同时把 `Core/Src/usart.c` 中 USART2 改回 115200 |
| 连接状态通知 | `AT+NOTI1` | 连接后模块回 `OK+CONN<mac>`，固件开机自动配置 |
| 恢复出厂 | `AT+DEFAULT` | 重置为 9600 / BT24 / FFE0 |

## 4. 通信协议（一行一帧 JSON，UTF-8 无 BOM，`\r\n` 结尾）

### 4.1 上行遥测（STM32 → 小程序，连接后每 3 秒自动一帧，收到 QUERY 立即回一帧）

```json
{"t":25.3,"h":58.0,"v":1.02,"i":0.452,"u":12.100,"p":5.4,
 "relay":0,"alarm":0,"al":0,"as":0,"diag":0,"mask":0,"conf":0[,"dmsg":"..."]}
```

| 字段 | 含义 | 单位 |
|---|---|---|
| t / h | 温度 / 湿度（SHT30） | ℃ / %RH |
| v | 振动模值（QMI8658，含静态 1g） | g |
| i / u / p | 电流 / 母线电压 / 功率（INA226） | A / V / W |
| relay | 继电器状态 | 0=断开 1=吸合 |
| alarm | 告警标志（0/1） | 0/1 |
| al | 告警等级 | 0=无 1=注意(超阈值80%) 2=异常(超阈值) |
| as | 告警源位图 | bit0=温度 bit1=振动 bit2=电流 |
| diag | 诊断状态 | 0=正常 1=注意 2=异常 |
| mask | 故障位图 | 位0=过热 位1=过载 位2=振动 位3=不平衡 位4=轴承 |
| conf | 诊断置信度 | % |
| dmsg | 固件诊断描述（仅非正常时携带） | 英文文本 |

> **INA226 无效帧**：当 INA226（I2C）读取失败时，`i`/`u`/`p` 三个字段发送 `null`
> （而非 0.000），小程序显示 `--`，用于区分"传感器读数失败"与"电机真实断电/0电流"；
> 同时 UART1 串口会打印 `[INA226] Read FAILED, retry=N (check I2C wiring/addr)` 定位失败原因。

### 4.2 下行命令（小程序 → STM32）

```json
{"cmd":"QUERY"}                       // 立即回一帧遥测
{"cmd":"PING"}                        // 连通性测试
{"cmd":"RELAY","val":1}               // 继电器 1=吸合 0=断开
{"cmd":"LED","index":1,"state":1}     // 单个 LED：index 1~4，state 0/1（小程序仅暴露 LED1/LED2）
{"cmd":"BEEP","ms":200}               // 蜂鸣器短鸣（上限 1000ms）
{"cmd":"GETTH"}                       // 查询告警阈值 → {"ok":1,"cmd":"GETTH","temp":60.0,"vib":3.0,"curr":5.0}
{"cmd":"SETTH","temp":60.0,"vib":3.0,"curr":5.0}  // 修改阈值（缺省字段保留原值，校验范围后写入内部Flash）
```

### 4.3 应答

```json
{"ok":1,"cmd":"RELAY","val":1}        // 成功
{"ok":0,"cmd":"RELAY"}                // 失败（如模块未编译 RELAY）
{"ok":0,"cmd":"?"}                    // 无法解析
```

> 未知行（如 AT 响应 `+NOTI=1`、`OK`、`OK+CONN...`）由固件内部处理，小程序应忽略非 `{` 开头的数据。

## 5. 微信小程序使用步骤

小程序源码在 `SMART-M-BLE-Miniprogram/`：

1. 打开 **微信开发者工具** → 导入项目 → 选择 `SMART-M-BLE-Miniprogram` 目录；
2. AppID 可使用测试号（`touristappid` 游客模式）或你自己的小程序 AppID；
   > 真机调试 BLE 需要**正式 AppID**（游客模式不支持真机预览）；
3. 编译后点击「预览」用手机扫码，或开发者工具「真机调试」；
4. 手机打开蓝牙（**Android 还需开启系统定位服务**），点击「打开蓝牙」→「扫描设备」；
5. 找到 `BT24`（或改过的名字）→ 点击连接 → 自动订阅通知并回显实时数据；
6. 用「控制」区按钮远程控制继电器 / LED / 蜂鸣器，用「通信日志」查看原始帧。

**小程序隐私接口说明**：`app.json` 已声明 `scope.bluetooth` 权限；微信后台若要求
「用户隐私保护指引」，需在 mp.weixin.qq.com 配置收集蓝牙信息用途。

## 6. 验证与排错

| 现象 | 检查 |
|---|---|
| 扫描不到设备 | 模块是否上电（VBAT 3.3V）；是否靠近手机；Android 是否开启系统定位；模块是否被其他手机占用 |
| 连上但无数据 | 订阅通知是否成功（看日志）；波特率是否 9600（USART2）；固件是否已烧录新版本 |
| 收到乱码 | TX/RX 是否交叉；波特率是否一致（模块被改成 115200 而 MCU 仍是 9600） |
| 继电器/LED 无反应 | 先看「通信日志」是否有 `{"ok":1...}` 应答；确认对应模块编译开关 |
| 串口日志无 BT24 打印 | `APP_BT24_UART1_PRINTF_ENABLE` 是否为 1；`BSP_UART1_Printf` 只放行含 BT24/MQTT/WiFi/ESP8266 的行 |

**串口验证**：`AT+NOTI1` 开启后，手机连接瞬间 UART1 会打印 `[BT24] Phone connected`，
断开打印 `[BT24] Phone disconnected`，可作为链路自检。

## 7. 与 MQTT 云通道的关系

| 维度 | 华为云 MQTT | BT24 蓝牙 |
|---|---|---|
| 物理链路 | ESP8266（UART3）→ WiFi → 云 | BT24（USART2）→ BLE → 手机 |
| 上行 | 物模型属性上报（3s） | 透传 JSON 遥测（3s） |
| 下行 | LED_Control / RELAY_Control | LED / RELAY / QUERY / PING / BEEP |
| 断网 | 断网补传 + 自动重连 | 不受网络影响，本地直连 |
| 适用 | 远程、云端存储 | 现场、无网环境、调试 |

两者可同时启用（UART3 与 USART2 互不冲突），共用 `APP_DIAG` 数据源与
`APP_Relay_Control` / `BSP_LED_*` 控制入口，状态天然一致。
