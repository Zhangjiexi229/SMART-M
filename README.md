## 项目简介

SMART-M 是一套面向**工业电机运行状态监测**的嵌入式智能终端系统。系统以 STM32F407VET6 为主控，运行 FreeRTOS 实时操作系统，通过温湿度、六轴姿态、电源电流等多类传感器实时采集电机运行参数，在边缘端完成振动特征提取与故障诊断，实现**过热 / 过载 / 异常振动 / 不平衡 / 轴承故障**的自动识别与告警联动（继电器断电保护 + 蜂鸣器报警），并借助 ESP8266 通过 MQTT 协议将数据上报至**华为云 IoTDA** 平台，支持远程监控与命令下发。

系统采用 `Common / BSP / Protocol / APP` 四层软件架构，全部模块由条件编译开关统一管控，可按实际硬件裁剪固件，代码可读性与可维护性兼顾。

## 功能特性

### 传感器采集
| 传感器 | 型号 | 功能 |
|---|---|---|
| 温湿度 | SHT30 | 环境温湿度采集（软件 I2C，地址 0x44） |
| 六轴姿态 | QMI8658 | 三轴加速度 + 三轴陀螺仪，振动/姿态数据源（软件 I2C，地址 0x6B） |
| 电源监测 | INA226 | 母线电压 / 电流 / 功率监测，过流自动断电保护（软件 I2C，地址 0x40，采样电阻 0.1Ω） |

### 边缘智能
- **振动特征提取**：1 秒滑动窗口，计算 RMS / 峰值 / 峭度 / 峰值因子；
- **故障诊断规则引擎**：输出 `正常 / 注意 / 异常` 三级状态，并生成 `过热 / 过载 / 振动异常 / 不平衡 / 轴承` 故障位图；
- **滑动平均滤波**：10 点窗口，传感器数据去抖。

### 告警联动与安全保护
- 三路独立告警阈值：**温度（℃）/ 振动（g）/ 电流（A）**；
- 迟滞恢复机制，防止阈值边界抖动误报；
- 过流 / 超限自动断开**继电器**（串接电机电源回路）并驱动**蜂鸣器**报警；
- 阈值可通过 4×4 矩阵键盘现场调整，并持久化到 STM32 **内部 Flash**（Sector11），重启不丢失。

### 云平台接入
- **ESP8266 + Paho MQTT Embedded C** 连接华为云 IoTDA（非加密 1883 端口）；
- 按**华为云物模型** JSON 格式周期上报属性（temperature / humidity / 电流 / 振动特征等）；
- 订阅云端下行命令主题，支持远程控制 **LED / 继电器**，并回传命令响应；
- **断网补传**：断网期间数据存入 RAM 环形缓冲（300 条），重连后批量补发，不丢数据；
- 全链路断线自动重连（AT → WiFi → TCP → MQTT 逐级恢复）。

### 人机交互
- **4×4 矩阵键盘**：页面切换、继电器控制、蜂鸣器测试、告警阈值设置；
- **OLED（SSD1306）**：实时数据 / 阈值配置 / 系统状态三页面显示，告警时闪烁提示。

## 硬件设计

| 模块 | 型号 / 规格 | 接口 | 说明 |
|---|---|---|---|
| 主控 | STM32F407VET6 | — | Cortex-M4F @168MHz，512KB Flash |
| 无线 | ESP8266 | UART3（DMA + IDLE 判帧） | AT 指令驱动 |
| 温湿度 | SHT30 | 软件 I2C（PB8=SCL / PB9=SDA） | 地址 0x44 |
| 六轴 IMU | QMI8658 | 软件 I2C | 地址 0x6B |
| 电源监测 | INA226 | 软件 I2C | 地址 0x40，0.1Ω 采样电阻 |
| 显示屏 | OLED SSD1306 | 软件 I2C（PD6=SCL / PD7=SDA） | 实时/阈值/状态三页面 |
| 键盘 | 4×4 矩阵键盘 | 行 PE2/PE6/PE7/PE10，列 PE8/PE9/PE11/PE12 | 行扫描 + 列读取 |
| 继电器 | 高电平吸合 | PA4 推挽输出 | COM/NO 串接电机电源回路 |
| 蜂鸣器 | 有源 | PA5（NPN 驱动） | 高电平响 |
| 存储 | STM32 内部 Flash | Sector11 @ 0x080E0000 | 告警阈值持久化 |
| 按键 | WK_UP=PA0 / KEY0=PE4 / KEY1=PE3 | GPIO | 独立按键（当前停用） |

> 详细引脚与功能配置见 [`文档/器件引脚与功能配置总表.md`](文档/器件引脚与功能配置总表.md)

## 软件分层

| 层级 | 目录 | 职责 |
|---|---|---|
| `APP` | `usrcode/APP` | FreeRTOS 任务、业务逻辑：采集、诊断、告警、补传、MQTT 上云 |
| `Protocol` | `usrcode/Protocol` | Paho MQTT 平台移植层（`mqtt_port`）、通信协议 |
| `BSP` | `usrcode/BSP` | 板级外设驱动：传感器、显示、键盘、继电器、Flash 存储等 |
| `Common` | `usrcode/Common` | 环形缓冲区、通用工具、**模块条件编译开关**（`module_cfg.h`） |

**模块裁剪**：所有模块在 [`usrcode/Common/Inc/module_cfg.h`](usrcode/Common/Inc/module_cfg.h) 中通过 `#define XXX_ENABLE 1/0` 统一管控，禁用模块不参与编译，节省 Flash 与 RAM；模块间依赖关系在编译期通过 `#error` 强制检查。

## FreeRTOS 任务

| 任务 | 周期 | 说明 |
|---|---|---|
| `SHT30 采集` | 周期 | 温湿度采集 → 写入共享快照 |
| `QMI8658 采集` | 周期 | 六轴数据采集 + 姿态解算 → 共享快照 |
| `INA226 监测` | 周期 | 电压/电流/功率采集，过流自动断电保护 |
| `振动特征提取` | 1s 窗口 | RMS / 峰值 / 峭度 / 峰值因子 |
| `故障诊断` | — | 规则引擎，输出健康状态与故障位图 |
| `告警联动` | — | 三路阈值比较 + 继电器断电 + 蜂鸣器 |
| `MQTT 上云` | 3s 上报 | ESP8266 联网，Paho MQTT 上报/下行命令处理 |
| `断网补传` | — | 断网数据缓存（RAM 环形 300 条），重连批量补发 |
| `矩阵键盘` | — | 消抖 + 页面切换 / 继电器 / 阈值设置 |
| `OLED 显示` | — | 实时 / 阈值 / 状态三页面 + 告警闪烁 |

任务统一在 [`usrcode/APP/Src/app_tasks.c`](usrcode/APP/Src/app_tasks.c) 创建（与 CubeMX 生成的 `freertos.c` 保持隔离），集成点位于 `main.c` 与 `freertos.c` 的 USER CODE 区域。

## 环境要求

- **STM32CubeMX** 6.x（生成外设初始化代码，`.ioc` 工程文件见 `SMART-M.ioc`）
- **ARM GNU 工具链** `gcc-arm-none-eabi`（≥ 10.3）
- **CMake** ≥ 3.22 + **Ninja**
- 烧录工具：**STM32CubeProgrammer** 或 ST-Link 配套工具
- （可选）VS Code + clangd 用于代码索引

## 构建与烧录

```bash
# 1. 配置（生成 Ninja 工程）
cmake --preset Debug

# 2. 编译（自动生成 .hex / .bin）
cmake --build --preset Debug

# 3. 烧录（ST-Link 示例）
STM32_Programmer_CLI -c port=SWD -w build/Debug/SMART-M.hex
```

> 构建产物输出到 `build/` 目录（已加入 `.gitignore`）。

## 快速上手

1. **云端准备**：按 [`华为云IoTDA配置指南.md`](华为云IoTDA配置指南.md) 开通华为云 IoTDA（免费单元即可），创建产品（MQTT + JSON）、定义物模型服务（`Sensor`：`temperature` / `humidity` 属性，`LED_Control` 命令）、注册设备；
2. **修改配置**：将 [`usrcode/APP/Inc/app_mqtt.h`](usrcode/APP/Inc/app_mqtt.h) 中 WiFi 名称/密码、华为云 `clientId / username / password`、设备 ID 替换为你的实际参数（可用华为云在线鉴权工具生成）；
3. **编译烧录**：按上文构建流程生成固件并烧录；
4. **验证**：上电后 ESP8266 自动连网 → MQTT 连接 → 周期上报属性；在华为云控制台可看到实时数据，下发 `LED_Control` 命令可远程控制板载 LED；
5. **断网测试**：断开 WiFi，数据缓存于 RAM；恢复后自动补发全部缓存数据。

> ⚠️ 示例中的云端参数为开发阶段实测值，正式部署请务必替换为你自己的设备凭据。
